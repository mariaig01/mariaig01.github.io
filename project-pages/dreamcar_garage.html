Dream Car Garage
Founder & Chief Security Officer (CSO)
Web platform for car enthusiasts to curate and manage personalised dream car collections. Features a gamified evolution system, community leaderboards, and Carpedia, a comprehensive automotive database with 600+ vehicles across all major brands.
www.dreamcargarage.app
Project Details / Background
Co-founded Dream Car Garage as a passion project bringing together automotive enthusiasm and technology. As Chief Security Officer, responsible for the platform's security architecture, data protection strategy, and secure development practices from day one.
Designed and oversaw the implementation of user authentication flows, session management, and secure API communication. Ensured GDPR-compliant data handling for user accounts, saved garages, and interaction data across the platform.
The platform allows users to browse a curated catalogue of 600+ vehicles spanning hypercars, supercars, sports cars, track-focused machines, GTs, hot hatches, SUVs, and luxury models. Users build and save garage configurations, track their collection's evolution over time, and compete on community leaderboards.
Beyond security, contributed to product strategy, feature prioritisation, and the overall user experience. Helped shape the gamification mechanics, including the evolution system, garage scoring, and leaderboard ranking, that drive user engagement and retention.

Security Architecture • Authentication & Session Management • GDPR Compliance • API Security • Product Strategy • Feature Design • Gamification • Web Platform
